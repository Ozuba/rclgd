RosTfBroadcaster3D
==================

**Inherits:** `Node3D <https://docs.godotengine.org/en/stable/classes/class_node3d.html>`__

A spatial node that automatically broadcasts its 3D transform to a ROS 2 TF2 frame.

.. rst-class:: classref-introduction-group

Description
-----------

**RosTfBroadcaster3D** is a helper node that simplifies the process of sending coordinate transforms to ROS 2. As a descendant of `Node3D <https://docs.godotengine.org/en/stable/classes/class_node3d.html>`__, it automatically tracks its local transformation relative to a parent and broadcasts it as a ROS 2 TF transform.

This node is particularly useful for modeling robot joints, sensors, or objects in a simulation, as it handles the math and frequency management automatically.
