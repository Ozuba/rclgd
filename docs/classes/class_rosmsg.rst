RosMsg
======

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A dynamic wrapper for ROS 2 messages.

.. rst-class:: classref-introduction-group

Description
-----------

**RosMsg** provides a flexible way to handle ROS 2 messages within Godot. It uses **BabelFish** to dynamically translate ROS 2 message buffers into Godot-friendly `Variant <https://docs.godotengine.org/en/stable/classes/class_variant.html>`__ data and vice versa.

Fields can be accessed dynamically using :ref:`get_member()<class_RosMsg_method_get_member>` and :ref:`set_member()<class_RosMsg_method_set_member>`, or via Godot's property system if the message has been initialized.

To improve the development experience, **RosMsg** includes a utility to generate GDScript "wrapper" classes that provide IDE autocomplete for specific message types.
