RosLogger
=========

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A named ROS 2 logger, with the same API as rclpy's logger.

.. rst-class:: classref-introduction-group

Description
-----------

**RosLogger** writes messages through the ROS 2 logging system, so they get the standard severity formatting, honour ``--ros-args --log-level`` and ``RCUTILS_CONSOLE_OUTPUT_FORMAT``, and can be inspected with ROS tooling. Its API mirrors rclpy's logger: :ref:`debug()<class_RosLogger_method_debug>`, :ref:`info()<class_RosLogger_method_info>`, :ref:`warning()<class_RosLogger_method_warning>`, :ref:`error()<class_RosLogger_method_error>` and :ref:`fatal()<class_RosLogger_method_fatal>` take the message and an optional `Dictionary <https://docs.godotengine.org/en/stable/classes/class_dictionary.html>`__ standing in for rclpy's keyword arguments.

It cannot be created with ``new()``; get one from :ref:`RosNode.get_logger()<class_RosNode_method_get_logger>` (published on ``/rosout``), from :ref:`get_child()<class_RosLogger_method_get_child>`, or from :ref:`rclgd.get_logger()<class_rclgd_method_get_logger>` (console only, no node needed).

::

    var logger := ros_node.get_logger()
    logger.info("Simulation started")
    logger.warning("Wheel slip detected", {"throttle_duration_sec": 1.0})
    logger.debug("First contact", {"once": true})

    var lidar_logger := logger.get_child("lidar")
    lidar_logger.set_level(RosLogger.DEBUG)

\ **Filters:** The keyword dictionary accepts ``once`` (log only the first time), ``skip_first`` (skip the first time) and ``throttle_duration_sec`` (log at most once per period, measured on a steady clock). ``once`` cannot be combined with the others. As in rclpy, filter state is kept per call site, so the same line is throttled independently of other lines. Script call stacks are not tracked in release exports unless ``debug/settings/gdscript/always_track_call_stacks`` is enabled; filters then key on the message text instead (with a one-time warning), and log locations are omitted.

.. _class_RosLogger_method_log:

.. rst-class:: classref-method

`bool <https://docs.godotengine.org/en/stable/classes/class_bool.html>`__ **log**\ (\ message\: `String <https://docs.godotengine.org/en/stable/classes/class_string.html>`__, severity\: :ref:`LoggingSeverity<enum_RosLogger_LoggingSeverity>`, kwargs\: `Dictionary <https://docs.godotengine.org/en/stable/classes/class_dictionary.html>`__ = {}\ ) :ref:`🔗<class_RosLogger_method_log>`

Logs ``message`` at ``severity``, which must be :ref:`DEBUG<class_RosLogger_constant_DEBUG>`, :ref:`INFO<class_RosLogger_constant_INFO>`, :ref:`WARN<class_RosLogger_constant_WARN>`, :ref:`ERROR<class_RosLogger_constant_ERROR>` or :ref:`FATAL<class_RosLogger_constant_FATAL>`. ``kwargs`` takes the optional filters ``once``, ``skip_first`` and ``throttle_duration_sec`` (see the class description). Any other key, or a value of the wrong type, is an error.

Returns ``true`` if the message was emitted, and ``false`` if it was below the logger's level or suppressed by a filter.
