RosActionClient
===============

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A ROS 2 Action Client for sending goals to an action server.

.. rst-class:: classref-introduction-group

Description
-----------

**RosActionClient** allows Godot to send goals to ROS 2 action servers. It is created through :ref:`RosNode.create_action_client()<class_RosNode_method_create_action_client>`.

Actions are designed for long-running tasks: unlike services they provide continuous feedback while the goal executes, and they can be canceled mid-flight.

Use :ref:`create_goal()<class_RosActionClient_method_create_goal>` to build a goal message, then :ref:`send_goal()<class_RosActionClient_method_send_goal>` to dispatch it. The returned :ref:`RosGoalHandle<class_RosGoalHandle>` acts as a handle for the in-flight goal: connect to its signals or ``await`` them to track acceptance, feedback and the final result.

::

    var client = ros_node.create_action_client("fibonacci", "example_interfaces/action/Fibonacci")
    if client.wait_for_server(2.0):
        var goal = client.create_goal()
        goal.order = 10
        var handle = client.send_goal(goal)
        handle.feedback.connect(func(msg): print("Partial: ", msg.sequence))
        await handle.completed
        if handle.get_status() == RosGoalHandle.STATUS_SUCCEEDED:
            print("Result: ", handle.get_result().sequence)
