RosTfListener3D
===============

**Inherits:** `Node3D <https://docs.godotengine.org/en/stable/classes/class_node3d.html>`__

A spatial node that automatically updates its 3D transform from a ROS 2 TF2 frame.

.. rst-class:: classref-introduction-group

Description
-----------

**RosTfListener3D** is a helper node that simplifies the process of receiving coordinate transforms from ROS 2. As a descendant of `Node3D <https://docs.godotengine.org/en/stable/classes/class_node3d.html>`__, it automatically queries the ROS 2 TF2 tree and updates its local transformation to match the spatial relationship between two specified frames.

This node is ideal for aligning Godot objects (like cameras, robot models, or visual markers) with their real-world or simulated counterparts in a ROS 2 system.
