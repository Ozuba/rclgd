RosSubscriber
=============

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A ROS 2 Subscriber for receiving messages from a topic.

.. rst-class:: classref-introduction-group

Description
-----------

**RosSubscriber** allows Godot to listen for :ref:`RosMsg<class_RosMsg>` data from other ROS 2 nodes. It is created through :ref:`RosNode.create_subscription()<class_RosNode_method_create_subscription>`.

When a new message is received on the topic, the callback provided during creation is triggered, passing a :ref:`RosMsg<class_RosMsg>` instance as its only argument.

The subscription remains active as long as this object is not freed.
