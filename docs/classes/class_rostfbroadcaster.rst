RosTfBroadcaster
================

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A broadcaster for coordinate transforms in the ROS 2 TF2 system.

.. rst-class:: classref-introduction-group

Description
-----------

**RosTfBroadcaster** allows Godot to send coordinate transforms (positions and rotations) to the ROS 2 transformation tree (TF2). It is created through :ref:`RosNode.create_tf_broadcaster()<class_RosNode_method_create_tf_broadcaster>`.

By sending transforms, you can communicate the spatial relationship between different parts of a robot or environment to other ROS 2 nodes.
