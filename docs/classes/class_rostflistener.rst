RosTfListener
=============

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A listener for coordinate transforms in the ROS 2 TF2 system.

.. rst-class:: classref-introduction-group

Description
-----------

**RosTfListener** allows Godot to query the current spatial relationships between different coordinate frames in the ROS 2 TF2 tree. It is created through :ref:`RosNode.create_tf_listener()<class_RosNode_method_create_tf_listener>`.

By listening for transforms, you can determine the position and rotation of robot parts, sensors, or other objects relative to each other or a global frame.

`Transform3D <https://docs.godotengine.org/en/stable/classes/class_transform3d.html>`__ **lookup_transform**\ (\ target_frame\: `String <https://docs.godotengine.org/en/stable/classes/class_string.html>`__, source_frame\: `String <https://docs.godotengine.org/en/stable/classes/class_string.html>`__\ ) :ref:`🔗<class_RosTfListener_method_lookup_transform>`

Attempts to find the coordinate transformation from ``source_frame`` to ``target_frame``. Returns a `Transform3D <https://docs.godotengine.org/en/stable/classes/class_transform3d.html>`__ representing the position and orientation of the source frame relative to the target frame.

If the transform is not found or is not currently available, it returns an identity transform. It is recommended to use :ref:`can_transform()<class_RosTfListener_method_can_transform>` first to check for availability.
