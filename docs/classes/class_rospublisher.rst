RosPublisher
============

**Inherits:** `RefCounted <https://docs.godotengine.org/en/stable/classes/class_refcounted.html>`__

A ROS 2 Publisher for sending messages to a topic.

.. rst-class:: classref-introduction-group

Description
-----------

**RosPublisher** allows Godot to send :ref:`RosMsg<class_RosMsg>` data to other ROS 2 nodes. It is created through :ref:`RosNode.create_publisher()<class_RosNode_method_create_publisher>` and is tied to a specific topic and message type.
